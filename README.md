# Image Editor

自分たち用のシンプルな画像編集ツール。今ある機能は色の塗り替えだけで、今後ほかの機能を足していく。

色の塗り替え: 黒一色のPNG素材を、カラーサークルで選んだ色に塗り替える。
色を動かすと読み込んだ全画像のプレビューがその場で変わり、フォルダごと書き出せる。
画像の処理はすべてブラウザ内で行い、サーバーには送らない。

https://260926-image-editor.vercel.app （mainへのpushでVercelに自動デプロイ）

## 使い方

1. PNGをドロップするか、「ファイルを選ぶ」「フォルダを選ぶ」で読み込む（サブフォルダも読む）
2. カラーサークル・HEX・HSB/RGBの数値・スポイトで色を決める。白い背景を消したいときは「白い部分を透明にする」をオンにする
3. 「フォルダに保存」（Chrome / Edge）または「ZIPで保存」（その他のブラウザ）。⌘Sでも保存できる

## 変換のルール

- 黒を指定色に塗り替える。白い部分は、そのまま白で残す（既定）か透明にするかを選べる
  - 白を残す: 中間のグレーは指定色と白の中間の色になる。もともと透明な部分は透明のまま
  - 白を透明にする: 暗さを不透明度として扱う。黒は指定色で不透明に、白は透明になり、中間のグレーは半透明になる
- 透過背景に黒で描いたPNGは、どちらの設定でも同じ結果になる
- 透過背景のPNGも白背景のPNGも同じルールで処理でき、アンチエイリアスの縁もなめらかに残る
- 書き出しは元画像と同じ解像度。黒だった部分の色は指定したRGB値ちょうどになる

## 保存先

- 「フォルダに保存」は、選んだフォルダの直下に、元のフォルダの中の構成のまま保存する。元のフォルダ名のフォルダは作らない（`icons/sub/b.png`を読み込んで`out`を選ぶと`out/sub/b.png`）
- 同じ名前のファイルがすでにあるときは、件数と名前を出して確認してから上書きする。読み込み元のフォルダを選んでしまったときも、ここで止められる
- 前回の保存から外した画像のファイルは、消さずにそのまま残る
- 「ZIPで保存」は`<元フォルダ名>-<HEX>.zip`（例: `icons-E53935.zip`）の中に同じ名前のフォルダを作って入れる。ばらばらのファイルを読み込んだ場合は`recolor-<HEX>`になる

## 開発

```bash
pnpm install
pnpm dev        # http://localhost:3200
pnpm test       # Vitest
pnpm test:e2e   # Playwright（本番ビルドを起動して実行。初回のみ pnpm exec playwright install chromium）
pnpm lint       # Biome
pnpm typecheck
pnpm build
```

Next.js 16（App Router）/ Tailwind CSS v4 / Biome / Vitest / Playwright。PNGの書き出しはfast-png、ZIPはfflate、保存結果の通知はsonner。
