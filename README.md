# いろがえ

黒一色のPNG素材を、カラーサークルで選んだ色に塗り替えるツール。
色を動かすと読み込んだ全画像のプレビューがその場で変わり、フォルダごと書き出せる。
画像の処理はすべてブラウザ内で行い、サーバーには送らない。

## 使い方

1. PNGをドロップするか、「ファイルを選ぶ」「フォルダを選ぶ」で読み込む（サブフォルダも読む）
2. カラーサークル・HEX・HSB/RGBの数値・スポイトで色を決める
3. 「フォルダに保存」（Chrome / Edge）または「ZIPで保存」（その他のブラウザ）。⌘Sでも保存できる

## 変換のルール

- 暗さを不透明度として扱う。黒は指定色で不透明に、白は透明になり、中間のグレーは半透明になる
- 透過背景のPNGも白背景のPNGも同じルールで処理でき、アンチエイリアスの縁もなめらかに残る
- 書き出しは元画像と同じ解像度。色は指定したRGB値ちょうどになる

## 保存先

選んだ場所に`<元フォルダ名>-<HEX>`（例: `icons-E53935`）という新しいフォルダを作り、元のフォルダ構成のまま保存する。
読み込み元と同じフォルダを選んでも、元の画像は上書きされない。
ばらばらのファイルを読み込んだ場合、フォルダ名は`recolor-<HEX>`になる。

## 開発

```bash
pnpm install
pnpm dev        # http://localhost:3200
pnpm test       # Vitest
pnpm lint       # Biome
pnpm typecheck
pnpm build
```

Next.js 16（App Router）/ Tailwind CSS v4 / Biome / Vitest。PNGの書き出しはfast-png、ZIPはfflate。
